MAMI TPS - EXTRACCION VISUAL STAGE0

Contenido:
- MGM_converter.py.py : conversor Python reutilizable.
- stage0_visual.obj + stage0_visual.mtl : OBJ con RGB por vértice (extensión no estándar de OBJ).
- stage#_visual_standard.obj + stage#_visual_standard.mtl : OBJ estricto, sin RGB por vértice.

Prueba realizada:
- Entrada: stage#.mgm (59,844 bytes).
- 12 materiales.
- 5 regiones normales y 1 región de fondo.
- 1,509 vértices / 503 triángulos exportados.
- 22 grupos material-región con geometría.
- La lectura termina exactamente antes de collisionNum (74); no se exportan colisiones ni enemigos.

Uso:
  python MGM_converter.py stage#.mgm

Con texturas extraídas del APK:
  python MGM_converter.py stage#.mgm --textures carpeta_texturas

El conversor busca nombres como sky21.png, image47.png, etc. y copia las texturas encontradas junto al OBJ.
Si tu programa 3D no acepta RGB extra en los vértices, importa stage#_visual_standard.obj.
El OBJ y su MTL correspondiente deben permanecer en la misma carpeta.

Las coordenadas XYZ se escalan por 0.1, tal como hace FieldRegion.create().
Los UV y el orden de triángulos se conservan. Los JumpPoint se leen para mantener la posición
del cursor, pero no se dibujan como malla.
